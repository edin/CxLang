# CX Feature Guides

These guides describe CX behavior that is implemented and covered by the
compiler test suite. CX is still experimental, so syntax and semantics may
evolve.

For progressive language documentation, start with the
[CX Language Guide](../language/README.md).

- [Initializers and typed AST macros](initializers-and-typed-macros.md) — from
  ordinary struct construction and inferred fixed arrays through typed macro
  results, element splicing, initializer directives, and reflection-driven
  metadata generation.
